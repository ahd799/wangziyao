━━ 推荐方式（99% 人选这个，不用装 Git）━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  双击运行  【推荐 - GitHub网页上传.cmd】
  → 会自动：1）把新版 index.html 内容复制到剪贴板
            2）帮你打开仓库里 index.html 的编辑页
  → 你只需要：
      1. 登录 GitHub 账号（如未登录）
      2. 点页面右上角的 ✏ 铅笔图标（"Edit in place"）
      3. Ctrl+A 全选旧代码 → Ctrl+V 粘贴新版
      4. 页面底部 "Commit changes" → 点绿色 "Commit changes" 按钮

  等 10~30 秒，GitHub Pages 会自动发布
  刷新 https://ahd799.github.io/wangziyao/ 即可看到新网站 ✨


━━ 备选方式（你本地 clone 了仓库时用）━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  双击 【本地Git仓库一键替换.cmd】，按里面给的 4 行命令
  （Copy + git add + git commit + git push）


━━ 为什么图片不用重新上传？━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  原站仓库根目录本来就有这 13 个文件：
    avatar.jpg  en.png  gs.jpg  zh.jpg  de.png
    hu.png      uo.png  yi.png  er.jpg  es.jpg
    hi.jpg      xu.jpg

  新版 index.html 用的是相对路径： ./avatar.jpg 、 ./en.png ...
  和你原来的图片放在同一目录 → 直接复用，一个字节都不用动。
  就算图片以后要换，只要文件名不变，HTML 自动用新图。
